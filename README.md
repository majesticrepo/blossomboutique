# Blossom Boutique

A static single-page site for Blossom Boutique, a handcrafted floral shop. Built with plain HTML, CSS, and JavaScript — no build step required.

## Project structure

```
index.html        Page markup
css/style.css      Styles
js/main.js         Nav scroll effect, colour/detail page switching, petal animation
images/            Site imagery
```

## Running locally

Any static file server works. For example:

```bash
npx serve .
```

Then open the printed local URL in your browser.
